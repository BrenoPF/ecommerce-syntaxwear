# SyntaxWear - E-commerce de Sneakers

Bem-vindo ao repositório do **SyntaxWear**, um projeto de front-end para um e-commerce moderno e responsivo focado em tênis e sneakers.

![SyntaxWear Logo](imagens/Logo.png)

## 📋 Sobre o Projeto

Este projeto consiste na interface principal (Home) de uma loja online de calçados urbanos e esportivos. O design foi focado em uma estética "Dark/Modern" com elementos vibrantes, garantindo uma experiência de usuário fluida em dispositivos Desktop, Tablets e Mobile.

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e acessível.
- **CSS3**: Estilização moderna, uso de Variáveis CSS (`variables.css`), Flexbox e CSS Grid.
- **Design Responsivo**: Media Queries para adaptação a diferentes tamanhos de tela.

## 📂 Estrutura do Projeto

A organização dos arquivos segue uma estrutura modular para facilitar a manutenção:

```
ecommerce-syntaxwear/
│
├── index.html              # Arquivo principal da página Home
│
├── css/                    # Folhas de estilo
│   ├── reset.css           # Reinicialização de estilos padrão do navegador
│   ├── variables.css       # Variáveis globais (fontes, cores)
│   ├── style.css           # Estilos globais e utilitários (.btn, body)
│   ├── header.css          # Estilos do cabeçalho e menu de navegação
│   ├── hero.css            # Estilos da seção principal (banner)
│   ├── product-category.css # Estilos dos cards de categoria
│   ├── product-grid.css    # Estilização do grid de produtos em destaque
│   └── footer.css          # Estilos do rodapé
│
└── imagens/                # Lixo de arquivos de mídia
    ├── banners/            # Imagens de fundo e banners
    ├── icons/              # Ícones do sistema e redes sociais
    ├── products/           # Imagens dos produtos
    └── Logo.png            # Logotipo da marca
```

## ✨ Funcionalidades

- **Header Responsivo**: Menu de navegação que se adapta para um menu "hambúrguer" lateral em dispositivos móveis.
- **Hero Section**: Banner principal com chamada para ação (CTA).
- **Categorias Interativas**: Cards de categorias (Casual, Esporte, Moderno, Futurista) com efeitos de hover.
- **Grid de Produtos**: Layout dinâmico em Grid (Bento Grid style) para destacar produtos populares.
- **Footer Completo**: Seção de inscrição em newsletter, redes sociais e links de navegação.

## 📱 Responsividade

O site foi otimizado para:

- **Desktop**: Layout amplo com menus horizontais e grid expandido.
- **Tablets**: Ajuste de colunas no grid de produtos e paddings laterais.
- **Mobile**: Menu lateral (off-canvas), empilhamento vertical de seções (stacking) e ajustes de toque.

## 🔧 Como Executar

1. Clone este repositório ou baixe os arquivos.
2. Navegue até a pasta do projeto.
3. Abra o arquivo `index.html` em seu navegador de preferência (Chrome, Firefox, Edge, etc.).

## 🎨 Fontes
